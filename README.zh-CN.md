# AgentLens Review Kit

一个可独立运行的 TypeScript 审查生命周期示例：提案、人工决定、执行回执、评价是四种独立对象。由钱磊根据私人 AgentLens 工作台的核心概念适配，缩小了合同，并补充输入检查，不代表完整原系统。

使用 Node.js 24，无需安装依赖。运行 `npm test` 验证行为，运行 `npm run example` 查看四组确定性合成示例。`node scripts/export-scenarios.mjs scenarios.json` 导出网站消费的示例记录。

覆盖允许试运行、拒绝后阻止执行、执行失败、证据不足。案例不调用模型，不访问外部服务，也不是模型质量评测。所有评价信号均由调用方提供，模块仅检查输入并应用规则。

`local_user` 字段不是真实身份认证；内容摘要不是数字签名。模块不承担持久化、多进程防重放、并发审查或分布式事务。真实集成应另行实现权限、存储、证据采集和并发控制。详见英文 README 和测试。
